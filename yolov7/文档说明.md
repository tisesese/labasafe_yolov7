# 基于嵌入式的实验室视频监控系统的设计与实现 —— 训练端工程文件

---

## 1. 项目概述

本项目基于 **YOLOv7** 目标检测框架，针对实验室安全场景训练了一个 **3 类目标检测模型**，检测目标为：

| class_id | 类别名称 | 说明 |
|----------|---------|------|
| 0 | fire | 火焰 / 明火 |
| 1 | person | 人员 |
| 2 | board card | 黑板 / 板卡 |

在原始 YOLOv7 基础上，本项目新增了以下改进：
- **SE 注意力模块**（Squeeze-Excitation）：可选集成到模型骨干网络中
- **Focal Loss**：替换默认 BCE 分类损失，解决类别不平衡问题
- **消融实验框架**：进行 4 组消融实验并生成对比图表

## 4. 模型训练

### 4.1 基础训练命令

```bash
python train.py \
    --weights yolov7.pt \
    --cfg cfg/training/yolov7.yaml \
    --data mydata_YOLO_clean/data.yaml \
    --hyp data/hyp.scratch.p5.yaml \
    --epochs 100 \
    --batch-size 6 \
    --device 0 \
    --img-size 640 640 \
    --workers 4 \
    --name exp_baseline
```

## 5. 消融实验

### 5.1 实验设计

| 实验编号 | 注意力模块 | 损失函数 | 实验名称 |
|----------|-----------|---------|---------|
| 1 | none | BCE | `ablation_clean_baseline_full` |
| 2 | SE | BCE | `ablation_clean_se_full` |
| 3 | none | Focal | `ablation_clean_focal_full` |
| 4 | SE | Focal | `ablation_clean_se_focal_full` |

所有实验使用相同的数据集（`mydata_YOLO_clean`）和超参数配置。

### 5.2 一键运行消融实验（Windows）

```cmd
run_ablation_clean.bat 100 6 0
```

该脚本会自动：
1. 依次运行 4 组训练实验
2. 调用 `eval_ablation.py` 收集结果到 CSV
3. 调用 `plot_ablation.py` 生成对比图表

### 5.3 恢复中断的实验

```cmd
resume_ablation_clean.bat 100 6 0
```

### 5.4 收集实验结果

```bash
python eval_ablation.py --preset clean --output ablation_results_clean.csv
```

### 5.5 生成对比图表

```bash
python plot_ablation.py --csv ablation_results_clean.csv --out_dir figures_clean
```

    --view-img
