# 基于嵌入式的实验室视频监控系统的设计与实现 —— 部署端工程文件

---

## 1. 项目概述

本项目是一个**端到端的实验室安全检测系统**，基于 YOLOv7 目标检测模型，部署于华为 Ascend（昇腾）边缘设备，实现以下三大功能：

| 功能模块 | 说明 |
|----------|------|
| **危险区域入侵检测** (Danger Zone) | 检测人员是否进入预设的危险区域，触发入侵报警 |
| **黑板/板卡计数** (Board Counter) | 实时统计画面中的板卡数量，低于阈值时发出报警 |
| **火焰检测** (Fire Alarm) | 检测画面中是否出现明火，发现火焰立即报警 |

---

## 3、部署流程

### 3.1配置好板卡开发环境（按照华为文档流程执行）

​	1、制卡：将包含OS、CANN软件的镜像烧录到SD卡，用于启动运行开发者套件。

​	制卡时eth1网口默认静态IP地址为192.168.137.100；eth0网口为DHCP动态模式，未分配IP地址；Type-C接口默认静态IP地址为192.168.0.2；

​	2、安装windows的usb网卡驱动

​	3、配置pc接口ip地址

​	4、远程登录

​	5、根据需要看是否修改开发者套件网口ip地址

### 3.2 模型导出（ONNX → OM）

```bash
# 步骤 1：PyTorch → ONNX（前面已执行）
# 步骤 2：ONNX → Ascend OM（使用 ATC 工具）
# AIPP 配置文件 aipp_new.cfg 指定输入预处理方式（如 RGB888_U8）
   atc --model=yolov7_last_quant_model.onnx\
    --framework=5\
    --output=yolov7_last_quant_model\
    --input_format=NCHW \
    --input_shape="images:1,3,640,640" \
    --soc_version=Ascend310B4 \
    --insert_op_conf=aipp_new.cfg \
    --log=error
```

**AIPP 配置文件示例 (`aipp_new.cfg`)：**
```
yolov7量化使用后模型：
aipp_op {
    aipp_mode : static
    input_format : RGB888_U8  
    src_image_size_w : 640
    src_image_size_h : 640
    crop : false
    csc_switch : false
    rbuv_swap_switch : false
    mean_chn_0 : 0
    mean_chn_1 : 0
    mean_chn_2 : 0
    min_chn_0 : 0.0
    min_chn_1 : 0.0
    min_chn_2 : 0.0
    var_reci_chn_0: 0.00392156862745098
    var_reci_chn_1: 0.00392156862745098
    var_reci_chn_2: 0.00392156862745098
}
```

### 3.4 设置模型路径

有两种方式指定 `.om` 模型文件路径：

**方式一：修改代码中的默认路径**

编辑 `ui_app_main.py` 中的变量：
```python
YOLOV7_MODEL_PATH_PLACEHOLDER = "/home/HwHiAiUser/lab_detection_system/model/best_aipp_new.om"
```

**方式二：通过环境变量覆盖**
```bash
export YOLO_MODEL_PATH=/home/HwHiAiUser/lab_detection_system/model/best_aipp_new.om
```

### 3.4 启动系统

```bash
cd /home/HwHiAiUser/lab_detection_system
python3 app_main.py
```
